# Học HSK 3.0 (HSK 1 + HSK 2)

App học tiếng Trung bằng tiếng Việt theo giáo trình New HSK 1 và New HSK 2 (bản 3.0), dùng riêng cho nhóm học.

- Nút **HSK 1 | 2** ở góc trên để chuyển cấp độ (tiến độ, huy hiệu lưu riêng từng cấp).
- `index.html` – app · `lv2.js` – giáo trình HSK 2 · `wb2.js` – Sổ tay & đề thi thử HSK 2
- `audio/`, `img/` – file nghe & ảnh HSK 1 · `audio2/` – file nghe HSK 2
- `firebase-config.js` – để trống = chạy không cần đăng nhập; dán cấu hình Firebase để bật tài khoản học viên.

## Đăng lên GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save. Sau 1–2 phút app có ở
